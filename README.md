# tools

Open source tools built on the [Crustdata](https://crustdata.com) API. Each folder is a standalone app with its own README.

| Tool | What it does |
|---|---|
| [company-researcher](company-researcher) | Type a company domain or name, get a research brief: headcount by department and location, hiring, executives with start dates, funding, traffic, tech stack, news and three questions to ask. Web app, JSON API and CLI. Live at [crustdata-researcher.vercel.app](https://crustdata-researcher.vercel.app). |
